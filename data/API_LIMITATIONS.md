# Limitações da football-data.org

## Dados disponíveis

- calendário
- resultados
- classificação
- equipas
- competição
- jornada
- local
- árbitros

## Dados não disponíveis no plano atual

- onze inicial
- banco
- substituições
- cartões
- marcadores detalhados
- estatísticas por jogador
- remates
- posse
- xG
- eventos minuto a minuto

## Consequência

A API será usada como fonte estrutural para calendário e resultados.

As métricas avançadas exigirão outra fonte ou introdução manual.
